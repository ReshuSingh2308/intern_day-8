# Superstore Sales Analysis

## Overview
This report provides a comprehensive analysis of Superstore sales, highlighting key performance trends across different segments, categories, and regions.

## Key Insights
- **Regional Performance:** The West region leads in both sales and profit.

- **Loss-Making Items:** Despite high sales, the Tables category incurs losses.
- **Segment Distribution:** Sales are distributed across Consumer, Corporate, and Home Office segments.
- **Sales Trends:** Monthly sales vary throughout the year, with notable fluctuations.
